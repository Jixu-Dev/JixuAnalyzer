# JixuAnalyzer

JixuAnalyzer is a modern web application for **GitHub profile analytics & visualization**.  
It provides interactive charts and insights to help users understand GitHub activity, contributions, repos, and more.

## 🚀 Features
- Visualize GitHub activity and statistics
- Interactive charts and graphs
- Clean and responsive UI
- Built with modern frontend tooling

## 🧰 Tech Stack
- Vite
- Tailwind CSS
- JavaScript
- HTML & CSS

## 📦 Installation

```bash
git clone https://github.com/Jixu-Dev/JixuAnalyzer.git
cd JixuAnalyzer
npm install
npm run dev

```
Open http://localhost:5173 in your browser.
